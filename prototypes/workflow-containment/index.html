Temporal UI design exploration

Workflows as containers, not events

Three static directions for a single timeline that can show a workflow and its descendants. Each concept uses the same visual grammar for the root and child workflows; indentation or nesting is the only distinction.

Option A · balanced

Nested workflow lanes

Every workflow owns an expandable lane. Its actions sit beneath its duration header; child workflow lanes nest recursively in the same list.

OrderWorkflow
PaymentWorkflow
Best balance of scanability, recursive hierarchy, and implementation fit.
Option B · compact

Hierarchy brackets

Keep dense event rows, but replace the workflow event row with persistent brackets that group the rows belonging to each workflow.

Highest information density; containment is structural rather than spatial.
Option C · expressive

Nested duration frames

Workflow lifetime becomes a visible frame on the timeline. Child workflow frames are literally nested inside their parent’s duration.

OrderWorkflow
PaymentWorkflow
Strongest “workflow contains work” message; needs care at high nesting depth.
